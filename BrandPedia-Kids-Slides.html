AI Engineering

AI done responsibly, for kids.

🗣️

Dual-voice podcast

Picks one male + one female voice from getVoices(), distinguishes by pitch; supports speed control and segment-seek.

🎲

Deterministic seeding (FNV)

Same input → same output, eliminating SSR hydration mismatches for stable, reproducible content.

🧩

7 question types · 0 wrong answers

Every brand's distractors come from other brands' real data, so options never repeat — and correctness is fully verified.

📡

SSE streaming generation

Exploring a new brand streams progress stage-by-stage (research → script → cards → save), synced live with the loading animation.
